# MADRock — Premium Fitness Coaching Platform

> **Train. Focus. Become Unstoppable.**

MADRock is a luxury, science-based fitness coaching web application built with Next.js 15, Tailwind CSS, Framer Motion, and Supabase.

---

## ⚡ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v3
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Backend / Database**: Supabase SQL
- **AI Integration**: Google Gemini Engine

---

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   ```bash
   cp .env.example .env.local
   ```
4. Run dev server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📋 Features Included

- **Full-Screen Hero**: Dark aesthetic overlay with animated statistics counters.
- **Auto-Scrolling Logo Marquee**: Infinite marquee for trusted gym partners.
- **9 Fitness Calculators**: Interactive calculators for BMI, TDEE, Macros, Protein, 1RM, Hydration, and Ideal Weight.
- **Exercise Library**: Searchable database categorized by muscle groups.
- **AI Coach**: Powered generator for workouts, meal plans, and 24/7 fitness chat.
- **Booking System**: Multi-step booking calendar with confetti feedback.
- **User Dashboard**: Daily workout protocol, meal targets, and metric logs.
- **Admin Panel**: Management console for users, revenue MRR, and bookings.
